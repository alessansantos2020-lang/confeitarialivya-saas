# Confeitaria Livya — SaaS de Delivery

Cardápio digital / delivery online multi-loja.

## Stack

- TanStack Start (React 19 + SSR) + Vite
- Supabase (banco, auth, storage)
- Tailwind CSS v4 + shadcn/ui
- Zustand (carrinho) + React Query (dados)

## Rodar localmente

```bash
npm install
npm run dev
```

O servidor sobe em `http://localhost:8080`.

As variáveis de ambiente do Supabase ficam no arquivo `.env`.
